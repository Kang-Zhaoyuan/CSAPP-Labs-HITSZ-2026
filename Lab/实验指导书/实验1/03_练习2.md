#### 5. 验证矩阵乘法内核的正确性

  编译和测试之前，请先在终端通过`cd`命令进入`lab1/build`目录。

  执行命令编译测试程序：

```bash
cmake -B . -S ../ && cmake --build ./ --target lab1_test_gemm_kernel.unittest
```

  运行测试：

```bash
./dist/bins/lab1_test_gemm_kernel.unittest --gtest_filter=gemm_kernel.test0
```
